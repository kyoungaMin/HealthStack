### 1. Tailwind CSS 충돌 수정 🎨

#### 문제점
리팩토링 후 Hero 섹션 텍스트(`text-white`, `text-emerald-50` 등)가 화면에서 사라짐.

#### 원인 분석
`app/healthstack/index.html`에 Tailwind CDN v3 스크립트와 Tailwind v4 PostCSS 빌드가 동시에 존재:

```html
<!-- index.html에 잘못 추가된 CDN v3 -->
<script src="https://cdn.tailwindcss.com"></script>

<!-- 실제 빌드: src/index.css의 @import "tailwindcss" (v4) -->
```

- Tailwind v4는 CSS 변수(`oklch()`) 기반으로 동작
- CDN v3가 이 CSS 변수들을 덮어써서 색상 클래스 전체 무효화

#### 해결
```html
<!-- 제거 -->
<script src="https://cdn.tailwindcss.com"></script>
```

`app/healthstack/index.html`에서 CDN v3 스크립트 라인 삭제. Tailwind v4 PostCSS 빌드만 사용.

### 2. 약국 지도 마커 onclick 오류 수정 🗺️

#### 문제점
```
TypeError: Cannot create property 'onclick' on string '<div style="...">1</div>'
```

#### 원인 분석
Kakao Maps JS SDK의 `CustomOverlay` API 동작 방식:
- `content: '<div>...</div>'` 형태로 문자열 전달 시
- `overlay.getContent()` 반환값은 **DOM 엘리먼트가 아닌 원본 문자열**
- 문자열에 `.onclick` 프로퍼티 할당 → TypeError

#### 해결
```tsx
// BEFORE (오류 발생)
const overlay = new kakao.maps.CustomOverlay({
  content: `<div style="...">1</div>`,
  map,
});
const contentEl = overlay.getContent() as HTMLElement; // 문자열 반환!
contentEl.onclick = () => setSelectedPharmacy(p); // TypeError

// AFTER (수정)
const contentEl = document.createElement('div');
contentEl.style.cssText = 'background:#059669; color:#fff; ...';
contentEl.textContent = String(i + 1);
contentEl.onclick = () => setSelectedPharmacy(p); // DOM 엘리먼트에 직접 설정
new kakao.maps.CustomOverlay({
  position: markerPosition,
  content: contentEl,  // DOM 엘리먼트 전달
  map,
});
```

### 4. 동네 약국 — 영업시간 표시 기능 추가 🕐

#### 배경
Kakao Maps JS SDK와 네이버 지역 검색 API 모두 영업시간 데이터를 직접 제공하지 않음.

#### 해결 방법
Kakao 검색 결과의 `place_url` 필드를 캡처하여 Kakao Maps 상세 페이지로 링크:
```tsx
// 약국 데이터 수집 시 place_url 추가
place_url: p.place_url || '',

// UI 렌더링
{p.place_url && (
  <a href={p.place_url} target="_blank" rel="noopener noreferrer"
     onClick={(e) => e.stopPropagation()}
     className="text-[11px] text-amber-600 font-bold bg-amber-50 px-2 py-0.5 rounded-full">
    🕐 영업시간 확인
  </a>
)}
```

거리(distance)도 함께 표시:
```tsx
{p.distance && (
  <span className="text-[10px] text-slate-400 flex-shrink-0">{p.distance}m</span>
)}
```

### 5. 지도 탭 재진입 시 지도 소멸 수정 🗺️

#### 문제점
다른 탭에 갔다가 동네 약국 탭으로 돌아오면:
- 약국 리스트는 유지됨
- 지도(Kakao Map)는 사라짐

#### 원인 분석
- `activeTab !== 'map'` 일 때 지도 컨테이너 div가 DOM에서 언마운트
- 탭 복귀 시 새 DOM 요소 생성되나 `naverMapRef.current`는 이전 Kakao Map 인스턴스 참조
- `initPharmacyMap()`이 `if (naverMapRef.current) return;` 로 초기화 스킵

#### 해결
```tsx
useEffect(() => {
  if (activeTab === 'map') {
    naverMapRef.current = null; // 강제 리셋 → initPharmacyMap 재실행 허용
    setTimeout(initPharmacyMap, 150); // DOM 마운트 대기 후 초기화
  }
}, [activeTab]);
```
